Sempre entregar arquivos em formato que o Mac execute diretamente: HTML, .sh (shell script), .command, ou texto com copy-paste claro.

**Why:** Usuário tem dificuldade com formatos que exigem ferramentas extras de instalação no Mac.

**How to apply:** Nunca entregar só código sem contexto de "onde colar". Preferir:
- Arquivos HTML que abrem no navegador
- Scripts .command (duplo clique no Finder)
- Instruções passo a passo com copy-paste direto no Terminal
- Apps Script direto no Google Sheets (sem instalar nada)
