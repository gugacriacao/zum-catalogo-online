## O que foi construído

### Arquivo principal: `loja.html`
Single-page app mobile-first com **8 telas**, tudo inline (HTML + CSS + JS), sem dependências externas.

| Tela | ID | Descrição |
|------|----|-----------|
| Catálogo | `s-home` | Grade de produtos 2 colunas, banner rotativo, chips de categoria |
| Produto | `s-product` | Galeria, cores, tamanhos, quantidade, botão adicionar |
| Sacola | `s-cart` | Lista de itens, subtotal, frete, total, botão finalizar |
| Dados | `s-data` | Formulário CPF (auto-fill), nome, e-mail, CEP (ViaCEP), endereço |
| Confirmar | `s-confirm` | Resumo do pedido + escolha PIX ou Cartão |
| PIX | `s-pix` | QR code, código copia-e-cola, timer 30min |
| Cartão | `s-card` | Número, nome, validade, CVV, parcelamento 1x–4x com juros |
| Sucesso | `s-success` | Confirmação de compra realizada |

## Decisões de arquitetura

- **Mídia (fotos/vídeos/banners):** iCloud → GitHub → Vercel (mesmo fluxo do portfólio do usuário). Script `PUBLICAR.command` (duplo clique) sincroniza tudo. **Ainda não criado.**
- **Estoque / pedidos / clientes:** Google Sheets ao vivo (ID: `1mPFvF1ryJg4-tUVwYccjFcWPzr8Bllv3UYXBBjvj8Rs`). Apps Script existente não é substituído.
- **Logos:** Embutidas como base64 diretamente nos atributos `src` — evita qualquer problema de autorização (Drive não funciona em iframe/site).
  - Logo branca → fundo preto (header do catálogo e tela de produto)
  - Logo preta → fundo branco (sacola, finalizar, confirmar, PIX, cartão, sucesso)
- **Pagamento:** Mercado Pago — PIX (0% juros) + Cartão 1x–4x com juros repassados ao cliente.
- **Juros cartão:** `{1: 0%, 2: 4,6%, 3: 6,5%, 4: 8,4%}`

## Banners

### Banner topo (rotativo)
- Lê arquivos `.txt` via `fetch()` em tempo real
- Se o `.txt` estiver em branco → slide não aparece
- Se todos em branco e sem imagem → usa texto padrão hardcoded
- Formato do `.txt`:
  ```
  tag: Nova coleção
  titulo: Verão 2026
  linha de baixo: Conheça os novos vestidos
  ```

### Banner meio (aparece no scroll)
- Só aparece se tiver **imagem + `produto.txt` com SKU válido**
- Clicar no banner vai direto para o produto
- `produto.txt` contém apenas o SKU, ex: `ZUM-VDRC-105`
