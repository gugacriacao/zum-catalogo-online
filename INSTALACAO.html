ZUM — Manual de Instalação

Loja Online · Conexão com Google Sheets · Apps Script

✦ O que vamos fazer
Em 4 passos você conecta a loja.html à planilha ZUM. Depois disso, todo pedido, lead e sacola abandonada cai direto no Sheets automaticamente.
  1. Passo 1 — Abrir o Apps Script da planilha
  2. Passo 2 — Criar o arquivo LojaOnline.gs e colar o código
  3. Passo 3 — Rodar a função criarAbas() uma única vez
  4. Passo 4 — Publicar o Web App e copiar a URL para a loja
1 Abrir o Apps Script
Abra a planilha ZUM no Google Sheets. No menu do topo clique em:
Extensões → Apps Script

Uma nova aba vai abrir com o editor de código.
📋   Planilha ZUM → menu Extensões → Apps Script
2 Criar o arquivo LojaOnline e colar o código
Dentro do editor do Apps Script:
1. Clique no + ao lado de "Arquivos" (painel esquerdo)
2. Escolha Script
3. Digite o nome: LojaOnline e pressione Enter
4. Apague o conteúdo que aparece (function myFunction...)
5. Cole o código abaixo (clique no botão azul para copiar)
⚠️ Importante: Apague TUDO que estiver no arquivo antes de colar. O arquivo deve conter apenas o código abaixo.
Código para colar no arquivo LojaOnline.gs

3 Criar as abas na planilha
Depois de colar e salvar o código (ícone de disquete ou ⌘S):
  1. No menu do topo do Apps Script, clique na lista de funções (onde diz myFunction ou similar)
  2. Selecione criarAbas
  3. Clique no botão ▶ Executar
  4. Vai pedir permissão — clique em Revisar permissões → Avançado → Acessar projeto ZUM (não seguro) → Permitir
  5. Uma janela vai aparecer dizendo "Abas criadas com sucesso!"
✅ Resultado: 5 abas novas vão aparecer na planilha: Pedidos Online, Leads, Sacola Abandonada, Funil Online, E-mails Enviados
4 Publicar o Web App e conectar à loja
Ainda no Apps Script:
  1. Clique no botão azul Implantar (canto superior direito)
  2. Clique em Nova implantação
  3. Clique no ícone de engrenagem ⚙ ao lado de "Tipo" e escolha App da Web
  4. Em "Executar como" deixe: Eu mesmo
  5. Em "Quem tem acesso" escolha: Qualquer pessoa
  6. Clique em Implantar
  7. Copie a URL do app da web que aparecer
A URL vai ser algo como:
https://script.google.com/macros/s/ABC123.../exec
Agora abra o arquivo loja.html em qualquer editor de texto (pode ser o TextEdit do Mac mesmo) e substitua esta linha:
Linha atual no loja.html — SUBSTITUIR
var AS_URL = 'COLE_AQUI_A_URL_DO_APPS_SCRIPT';
Por esta (cole a URL que você copiou no lugar indicado):
Linha nova — cole a URL do Apps Script aqui
var AS_URL = 'https://script.google.com/macros/s/COLE_SUA_URL_AQUI/exec';
Salve o loja.html e pronto. A loja está conectada à planilha.

Tudo pronto!

A partir de agora, cada vez que uma cliente:

Chegar na loja → registrado em Funil Online
Preencher os dados → registrado em Leads
Fechar sem comprar → registrado em Sacola Abandonada
Finalizar o pedido → registrado em Pedidos Online
Voltar e digitar o CPF → dados preenchidos automaticamente
